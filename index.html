Meet the creator

What it does

Any entity

Pick a mob, a player, or anything else in the game and give it a new hitbox size.

Hitbox only

The model and animations stay as they are. Only the box that decides what gets hit changes.

Made for fun

Silly mobs, odd minigames, mapmaking, and testing how the game reacts to strange sizes.

Fair play

Not a hacking tool.

Inaccurate Hitboxes is not made for cheating. It's a project built for experimenting, creating, and having a laugh.

Please don't use it to gain an advantage on servers that don't allow it, and follow the rules of any server you join.
